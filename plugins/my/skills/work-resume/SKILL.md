# 작업 이어서

스크립트: 이 스킬 폴더 기준 `../../scripts/work.mjs`를 Node로 실행한다.

## 할 일

1. `work.mjs latest`로 가장 최근 인계 문서를 읽는다.
2. `work.mjs context`로 지금 상태를 읽고 인계 문서와 비교한다: 브랜치가 같은지, 커밋 안 된 변경이 있는지. 인계 뒤 커밋은 인계 문서 파일 이름의 시각(YYYYMMDD-HHMM) 이후를 `git log --since`로 확인한다.
3. 인계 문서의 앞머리 `spec`에 명세가 있으면 그 명세도 읽는다.
4. 요약한다: 지난번에 한 일, 검증 결과, 주의할 것, 인계 뒤 달라진 점.
5. "다음 할 일"의 첫 항목을 시작해도 될지 묻는다. 승인되면 그 항목부터 진행한다.

질문은 선택지 질문 도구가 있으면 그것으로 묻고, 없으면 번호 목록으로 묻고 번호로 답을 받는다.

## 멈출 때

- 인계 문서가 없으면(스크립트 "작업 오류") 메시지를 보여 주고, `마이 작업 시작`으로 상황부터 볼지 묻는다. 인계 문서를 지어내지 않는다.
- 브랜치가 인계 문서와 다르면 알리고, 지금 브랜치에서 이어갈지 묻는다. 인계 문서의 브랜치로 가겠다고 하면 사용자가 직접 바꾼 뒤 다시 부르라고 안내하고 끝낸다. 브랜치를 바꾸지 않는다.
- "다음 할 일"이 비어 있으면 요약만 보여 주고 무엇을 할지 묻는다.

## 결과

- 끝: 인계 문서 경로, 요약, 달라진 점, 시작한 작업.
