# 논문 학습 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

- 첨부한 논문 PDF나 붙여 넣은 본문만 근거로 하고, 근거마다 절·페이지·그림·표 번호를 적는다. 논문에 없는 내용은 "논문 외", 확인하지 못한 것은 "미확인".
- arXiv 링크만 있고 웹 읽기가 안 되면 PDF를 첨부해 달라고 한다.

## 할 일

1. 문제, 방법, 실험 설정, 결과, 한계를 근거와 함께 정리한다. 저자가 주장한 것과 실험이 보여 준 것을 나눈다.
2. 질문에 답하고, 절마다 질문 하나로 이해도를 점검한다.
3. 노트: 주제·노트 이름·제목을 제안해 확인받고, `learn-class`의 학습 노트 양식(파일 이름 `미정-<노트 이름>.md`)으로 md를 준다. `sources`에는 논문 제목과 링크를 넣는다.

## 결과

- 정리, 이해도 점검 결과, 노트 md, "번호 미정 — 로컬에서 import" 한 줄.
