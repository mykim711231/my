# 설정 동기화 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

## 할 일

1. 원본 도구의 규칙 파일(`CLAUDE.md`, `AGENTS.md`, `GEMINI.md` 중 원본 것)과, 있으면 대상 도구의 규칙 파일을 첨부받는다.
2. 공통 규칙은 `AGENTS.md`가 갖는다. 원본에서 도구 전용이 아닌 규칙을 모아 `AGENTS.md` 전체 md를 준다.
3. 대상 규칙 파일(`CLAUDE.md` → `@AGENTS.md` 한 줄, `GEMINI.md` → `AGENTS.md`를 읽으라는 한 줄, Codex → `AGENTS.md` 그대로)과 남길 도구 전용 규칙을 준다.
4. 스킬 폴더 이동은 채팅에서 하지 않는다. 옮길 폴더 목록(원본 경로 → 대상 경로)만 준다. 도구별 스킬 폴더 위치는 "미확인 — 로컬 `마이 설정 동기화`가 확인한다".

## 결과

- 파일별 md와 로컬 경로, 옮길 스킬 목록, "적용은 사용자가".
