# 프로젝트 구현 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

## 할 일

1. 승인된 명세(`status: approved`), `docs/stack.md`, 계약 파일, 고칠 파일을 첨부받는다. 명세가 없으면 `마이 프로젝트 {name} 정의`부터 하라고 하고 멈춘다.
2. 기능 하나를 DB부터 API·화면·테스트까지 세로로 구현한 코드를 파일마다 코드 블록으로 준다. 블록 위에 프로젝트 기준 경로를 적는다. 기존 파일을 고치면 바뀐 부분이 아니라 파일 전체나 분명한 diff로 준다.
3. 생성물(계약에서 만드는 코드)은 직접 고치지 말고 원본과 다시 생성할 명령을 준다.
4. 확인할 명령(lint, 타입 검사, 테스트)을 주고 결과를 붙여 달라고 한다.

## 결과

- 파일별 코드, 확인 명령, "미검증 — 테스트 미실행". 결과를 붙여 주면 `마이 프로젝트 {name} 검증`으로 판정한다.
