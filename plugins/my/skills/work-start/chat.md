# 작업 시작 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

## 할 일

1. 첨부한 README·`docs/`·인계 md와 붙여 넣은 `git status`·`git log --oneline -10` 결과를 읽는다.
2. 아무것도 없으면 "무엇을 할지, 관련 파일이 있으면 첨부해 달라"고 묻고, 위 두 명령을 붙여 주면 더 정확하다고 한 줄 덧붙인다.
3. 프로젝트 목적, 현재 상태, 다음 작업 후보 세 개 이하를 브리핑한다.

## 결과

- 브리핑과 다음 작업 제안. 첨부에 없는 것은 "미확인".
