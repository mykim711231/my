# 작업 시작

파일을 만들거나 고치지 마라. 이 스킬은 읽기만 한다.

스크립트: 이 스킬 폴더 기준 `../../scripts/work.mjs`를 Node로 실행한다.

## 할 일

1. `work.mjs context`를 실행한다. 프로젝트 루트, 브랜치, 커밋 안 된 변경, 최근 커밋, 문서 목록, 명세별 진행, 최근 인계 문서가 나온다.
2. 나온 문서 중 상황 판단에 필요한 것을 읽는다: `AGENTS.md`(없으면 `CLAUDE.md`·`README.md`), `docs/stack.md`, status가 approved인 명세, 최근 인계 문서.
3. 브리핑한다: 이 프로젝트가 무엇인지, 지금 어디까지 왔는지, 커밋 안 된 변경이 무엇인지.
4. 다음 작업을 1~3개 제안한다. 인계 문서의 "다음 할 일"과 명세의 남은 작업을 먼저 쓰고, 근거(파일 이름)를 붙인다.
5. 어느 것부터 할지 묻는다. 질문은 선택지 질문 도구가 있으면 그것으로 묻고, 없으면 번호 목록으로 묻고 번호로 답을 받는다.

## 멈출 때

- 스크립트가 실패하면 오류 메시지를 보여 주고 끝낸다.
- git 루트가 없으면 "git 루트 없음 — 현재 폴더 기준"을 알리고 있는 문서만으로 브리핑한다.
- 제안할 근거(인계 문서의 다음 할 일, 명세의 남은 작업)가 없으면 "제안할 작업 없음"을 알리고 무엇을 할지 묻는다. 근거 없이 작업을 지어내지 않는다.

## 결과

- 끝: 브리핑, 제안한 다음 작업(근거 파일 포함), 사용자가 고른 작업. 고른 작업은 이 스킬이 끝난 뒤 진행한다.
- 직전 채팅을 이어서 하려면 `마이 작업 이어서`를 안내한다.
