# 플러그인 설정 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

설정 파일이 없으므로 이번 대화에서만 쓸 값을 정한다. 저장했다고 말하지 않는다.

## 할 일

1. 바꿀 항목을 고르게 한다: 학습 노트 주제 이름 규칙, 작업 종료 때 플러그인 불편 사항 질문(켬/끔).
2. 고른 값을 표로 보여 주고 "이번 대화에서만 적용"을 붙인다.
3. 로컬 설정(학습 폴더, 원본 경로)은 로컬 도구의 `마이 플러그인 설정`으로 바꾸라고 안내한다.

## 결과

- 이번 대화 설정 표.
