# 플러그인 설정

설정 파일(`~/.my/config.json`)은 아래 스크립트로만 읽고 쓴다. 파일을 직접 고치지 마라. 노트 파일은 옮기거나 지우지 마라.

스크립트: 이 스킬 폴더 기준 `../../scripts/config.mjs`를 Node로 실행한다.

## 할 일

1. **현황표**: `config.mjs table`을 실행하고 출력을 그대로 보여 준다.
   - 비대화형 실행이면 여기서 끝낸다. 아무것도 바꾸지 않는다.
2. **바꿀지 묻기**: "노트 위치·경로 / 켜고 끄기 / Mermaid 검사 방식 / 그대로 두기" 중 하나를 고르게 한다. 현황표에 "폴더가 없는 프로젝트 항목"이 있으면 "프로젝트 항목 정리"를 선택지에 더한다. "그대로 두기"면 끝낸다.
3. **항목별 질문**
   - 노트 위치·경로: 바꿀 항목을 고르게 한다: 저장 대상(`learn_target`) / 프로젝트 학습 폴더 이름(`project_learn_dir`) / 중앙 학습 폴더(`learn_root`) / 원본 경로(`plugin_src`).
     - `learn_target`: "프로젝트 학습 폴더(`project`) / 중앙 학습 폴더(`central`)". `central`을 골랐는데 `learn_root`가 없으면 이어서 `learn_root`를 묻는다.
     - `project_learn_dir`: 프로젝트 루트 기준 상대 경로. 절대 경로와 `..`는 받지 않는다.
     - `learn_root`, `plugin_src`: 절대 경로. `learn_root`는 현황표의 제안값을 선택지로 주고, 다른 경로는 직접 입력으로 받는다.
   - 켜고 끄기(`work_end_question`, `usage_log`): 여러 개를 한 번에 고르게 하고, 고른 것의 켬/끔을 바꾼다.
   - Mermaid 검사 방식(`mermaid_check`): "저장할 때마다(`hook`) / 완료 전에만(`finish`) / 끔(`off`)".
   - `learn_target`, `project_learn_dir`, `mermaid_check`는 값을 고르기 전에 "이 프로젝트만 / 전체 기본값"을 묻는다. 이 프로젝트만이면 `--project`를 붙인다. git 루트 밖이면 묻지 않고 전체 기본값으로 한다.
   - `learn_root`, `plugin_src`는 전체 기본값으로만 저장한다. 범위를 묻지 않는다.
   - 프로젝트 항목 정리: 항목마다 "지우기 / 새 경로로 옮기기 / 그대로 두기".
4. **미리보기**: 바꿀 것마다 저장 플래그 없이 실행한다. 출력의 diff를 보여 준다.
   - 값 바꾸기: `set <키> <값> [--project]`
   - 프로젝트 항목: `remove-project <경로>`, `move-project <경로> <새 경로>`
5. **승인**: "이대로 저장할까?"를 묻는다. 승인이 없으면 저장하지 않고 끝낸다.
6. **저장**: 미리보기와 같은 명령에 미리보기가 알려 준 `--write --expect <해시>`를 붙여 실행한다. 바꿀 것이 여러 개면 하나 저장할 때마다 다음 것의 미리보기를 다시 만들어 새 해시를 쓴다(해시는 저장 전 파일 기준이다).
7. **확인**: 저장 출력의 현황표를 보여 준다. 바꾼 항목의 출처가 `env`로 남아 있으면 "환경 변수가 새 값을 가리고 있다. 효과를 보려면 그 환경 변수를 지워야 한다"고 경고한다.

질문은 선택지 질문 도구가 있으면 그것으로 묻고, 없으면 번호 목록으로 묻고 번호로 답을 받는다.

## 멈출 때

- 스크립트가 "설정 오류"로 실패하면 그 메시지를 보여 주고 저장하지 않고 끝낸다. 파일을 직접 고치지 않는다.
  - 설정 파일 JSON이 깨졌다는 오류면, 사용자가 직접 고쳐야 한다고 안내한다.
  - "승인 뒤 설정 파일이 바뀌었다"면 미리보기부터 다시 하고 다시 승인을 받는다.
- 사용자가 "그대로 두기"나 거절을 고르면 바로 끝낸다.

## 결과

- 끝: 저장한 변경 한 줄씩 + 다시 읽은 현황표. 아무것도 바꾸지 않았으면 "변경 없음".
- 노트 위치를 바꿨으면 한 줄 덧붙인다: "기존 노트는 옮기지 않았다. 이전 위치에 그대로 있다."
- 설정은 이 PC에만 저장된다.
