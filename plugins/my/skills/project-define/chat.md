# 프로젝트 정의 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

## 할 일

1. 요구사항을 받는다. 기존 `docs/requirements.md`·`docs/stack.md`·명세가 있으면 첨부해 달라고 한다.
2. 요구사항을 ID(`REQ-001` …)가 붙은 목록으로 정리하고, 모호한 것은 질문으로 확인한다.
3. 기능 명세 초안(목표, 범위, 요구사항 ID, 작업 체크박스 `## 작업`, 검증 방법)과 계약 초안(API·데이터 형식)을 각각 md로 준다. 앞머리 `status: draft`.
4. 명세 승인을 받으면 앞머리를 `status: approved`로 바꾼 판을 다시 준다.

## 결과

- 요구사항 목록, 명세 md, 계약 md와 각각의 로컬 경로(`docs/specs/<기능>.md` 등). 프로젝트에 원래 쓰던 경로가 있으면 그것을 따른다.
