# 적대적 학습 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

대상(질문, 주장, 제안, 결정안, AI의 직전 답변)을 바로 받아들이지 않고 검토한다. 하위 에이전트를 쓰지 않으므로 결과 끝에 "분리 검토 아님"을 붙인다.

## 할 일

1. 대상과 그 전제를 한 줄씩 적는다. 전제를 확인할 원본(첨부, 붙여 넣은 글, 이 대화)이 없으면 "미확인"으로 둔다.
2. 허점, 반례, 미확인 가정을 찾는다. 반대마다 실패하는 구체적 시나리오(입력, 상태, 결과)를 든다.
3. 지적마다 심각도(높음·중간·낮음)와 근거를 단다. 참인 주장에 결함을 지어내지 않는다. 문제가 없으면 없다고 한다.

## 결과

- 지적 표(심각도, 지적, 시나리오, 근거), 결론 한 줄, "분리 검토 아님".
