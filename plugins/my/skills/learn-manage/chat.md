# 학습 관리 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

학습 폴더를 볼 수 없으므로 붙여 넣은 목록과 노트로만 판단하고, 적용은 로컬에서 하게 한다.

## 할 일

- **목록**: 학습 폴더의 `INDEX.md`를 붙여 달라고 하고 주제 표로 보여 준다. 없으면 이 대화에서 만든 노트(번호 미정) 목록을 보여 준다.
- **통합 {주제}**: 그 주제의 `index.md`와 노트를 첨부받아 합칠 노트, 나눌 소주제, 옮길 경로를 표로 제안한다. 적용은 로컬에서 `마이 학습 통합 {주제}`로 하라고 안내한다.
- **점검**: 첨부한 노트의 앞머리 필드(topic, tags, sources, updated), 절 제목, 깨진 링크를 본다. 번호·목록 점검은 로컬 `마이 학습 점검`으로 하라고 안내한다.

## 결과

- 표나 제안, "적용·번호 점검은 로컬에서" 한 줄.
