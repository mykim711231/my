# 플러그인 문제 기록

기록만 한다. 플러그인 파일을 고치거나 원인을 조사하지 마라. 고치는 일은 `마이 플러그인 개선`이 한다.

## 할 일

1. 기록할 값을 정한다.
   - 내용: 사용자가 준 `<내용>` 그대로. 다듬거나 요약하지 않는다.
   - 관련 스킬: 이 대화에서 방금 쓴 my 스킬 이름. 모르겠으면 비운다(추측해서 채우지 않는다).
   - 상황 요약: 문제가 생긴 직전 상황을 두세 문장으로. 사용자 입력, 무엇이 기대와 달랐는지. 비밀번호·토큰·키 같은 값은 넣지 않는다.
2. 이 스킬 폴더 기준 `../../scripts/issue.mjs`를 Node로 실행한다. 형식: `--skill <관련 스킬> --summary <상황 요약> -- <내용>`. 각 값은 하나의 인자로 넘긴다(따옴표로 감싼다).
3. 스크립트가 출력한 ID와 파일 위치를 보여 준다.
4. 하던 작업이 있었으면 그 작업으로 돌아간다.

채팅 모드(셸·파일 도구가 없거나 이 스킬 폴더 기준 `../../scripts`가 없음)면 이 본문 대신 같은 폴더의 `chat.md`를 따른다. 스크립트가 실행됐다가 실패한 것은 채팅 모드가 아니다.

## 멈출 때

- 내용이 비었으면 기록하지 않고 사용법 `마이 플러그인 문제 <내용>`만 보여 준다.
- 스크립트가 실패하면 오류 메시지와 함께 "기록 실패"로 끝낸다. 파일을 직접 만들지 않는다(ID 중복 방지가 깨진다).

## 결과

- 끝: "기록함: IMP-…" 한 줄과 파일 위치.
- 대기 중인 기록은 `마이 플러그인 현황`의 "개선 대기"에서 볼 수 있다고 한 줄 안내한다.
- 기록은 이 PC의 플러그인 데이터 폴더에만 있다. 다른 PC와 공유되지 않고, 플러그인을 지우면 함께 지워질 수 있다.
