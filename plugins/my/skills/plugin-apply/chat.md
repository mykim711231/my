# 플러그인 개선 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

채팅 모드에서는 하지 않는다. 플러그인 원본을 고치고 검증·버전 올림·커밋까지 해야 하기 때문이다.

- "로컬 도구(Claude Code, Codex 등)에서 `마이 플러그인 개선`을 쓴다"고 안내한다.
- 개선할 내용이 있으면 `마이 플러그인 문제 <내용>`으로 이슈 본문을 먼저 만들 수 있다고 한 줄 붙인다.
