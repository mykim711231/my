# 작업 현황

파일을 만들거나 고치지 마라. 이 스킬은 읽기만 한다.

## 할 일

1. 이 스킬 폴더 기준 `../../scripts/work.mjs status`를 Node로 실행한다.
2. 출력을 그대로 보여 준다. 다른 프로젝트는 보지 않는다.

채팅 모드(셸·파일 도구가 없거나 이 스킬 폴더 기준 `../../scripts`가 없음)면 이 본문 대신 같은 폴더의 `chat.md`를 따른다. 스크립트가 실행됐다가 실패한 것은 채팅 모드가 아니다.

## 멈출 때

- 스크립트가 실패하면 오류 메시지를 보여 주고 끝낸다. 파일을 직접 읽어 표를 만들지 않는다.

## 결과

- 끝: 현황 마크다운.
- 명세와 인계 문서가 없다고 나오면, 상황 브리핑은 `마이 작업 시작`, 인계 문서 작성은 `마이 작업 종료`를 안내한다.
