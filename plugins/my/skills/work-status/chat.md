# 작업 현황 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

## 할 일

1. 첨부한 인계 md(여러 개면 날짜가 가장 늦은 것)와 명세 md를 읽는다. 없으면 첨부해 달라고 한다. 이 대화만 있으면 이 대화에서 한 일로 만든다고 알리고 진행한다.
2. 할 일·진행·완료 표를 만든다. 명세의 `## 작업` 체크박스가 있으면 그것을 세고, 없으면 인계 md의 "다음 할 일"을 할 일로 둔다.

## 결과

- 표 하나와 근거 파일 이름. 첨부에 없는 상태는 "미확인".
