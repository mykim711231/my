# 수업 학습 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

- 첨부한 강의자료와 실습 코드만 근거로 답하고, 답마다 근거 위치(파일:줄 또는 페이지)를 적는다. 자료에 없는 내용은 "자료 외", 실행해 봐야 아는 동작은 "미확인".

## 할 일

1. **자료 받기**: 첨부가 없으면 첨부해 달라고 한다. 읽지 못한 파일은 목록으로 알린다. 자료 없이 일반 지식으로 수업하지 않는다.
2. **개요 → 질의응답 → 이해도 점검**: 단원 구조를 요약하고, 질문에 답하고, 단원마다 질문 하나로 점검해 맞음·부분·틀림과 근거를 알려 준다.
3. **노트**: 주제(영문 kebab-case)·노트 이름·제목을 제안해 확인받고, 아래 학습 노트 양식으로 md를 준다.

## 학습 노트 양식

- 파일 이름: `미정-<노트 이름>.md`. 번호는 로컬에서 매긴다.
- 로컬로 가져오기: `node <플러그인>/scripts/learn.mjs import <파일>` — 번호를 매기고 목록·이동 링크를 고친다.
- 소주제가 없으면 `subtopic` 줄을 지운다. 절 제목은 바꾸지 않는다.

```markdown
---
topic: "<주제>"
subtopic: "<소주제>"
tags: ["<분야>"]
sources: ["<자료:페이지>"]
updated: YYYY-MM-DD
---

# <제목>

## 요약

## 내용

## 이해도 점검
```

## 결과

- 개요, 이해도 점검 결과, 노트 md, "번호 미정 — 로컬에서 import" 한 줄.
