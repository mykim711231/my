# 프로젝트 배포 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

배포했다고 말하지 않는다. 배포는 사용자가 터미널에서 한다.

## 할 일

1. `docs/stack.md`와 명세의 검증 결과를 첨부받는다.
2. 점검표를 채운다: 검증 완료, 버전·lock 파일, 환경 변수·비밀 값 위치(값 자체는 받지 않는다), 마이그레이션, 빌드, 되돌리기 방법. 첨부로 확인하지 못한 항목은 "미확인".
3. 배포 명령과 되돌리기 명령을 순서대로 준다. 실행 결과를 붙여 주면 성공·실패를 판정한다.

## 결과

- 점검표, 배포·되돌리기 명령, "배포 미실행 — 사용자가 실행".
