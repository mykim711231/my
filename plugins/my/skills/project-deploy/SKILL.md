# 프로젝트 배포

- 배포는 되돌리기 어렵고 바깥에 영향을 준다. 명령마다 무엇을 어디에 하는지 보여 주고 실행 전 확인을 받는다. 한 번 받은 확인을 다음 명령에 쓰지 않는다.
- 배포 대상과 방법은 `docs/stack.md`의 배포 절을 따른다. 없으면 사용자와 정해 적는다.
- 비밀 값(토큰, 비밀번호, 키)은 읽거나 입력하거나 파일에 적지 않는다. 어디에 있어야 하는지만 확인하고 넣는 것은 사용자가 한다.

스크립트: 이 스킬 폴더 기준 `../../scripts/project.mjs`를 Node로 실행한다. 프로젝트 루트는 실행한 폴더의 git 루트로 정해지므로, 사용자의 원래 작업 폴더에서 스크립트의 절대 경로로 실행한다. 스킬 폴더로 이동해 실행하지 않는다.

## 할 일

1. **배포 방법 확인**: `docs/stack.md`에서 배포 절을 읽는다. 없으면 배포 대상(예: 정적 호스팅, 컨테이너, 서버), 환경(스테이징·운영), 배포 명령, 되돌리기 방법을 묻고 초안을 보여 준 뒤 승인받아 `docs/stack.md`에 "## 배포" 절로 더한다. 배포 도구의 사용법은 공식 문서로 확인하고 확인하지 못한 것은 "미확인"으로 둔다.
2. **체크리스트**: 아래를 확인해 항목마다 통과 / 실패 / 확인 불가와 근거를 보여 준다.
   - 배포할 명세가 모두 `status: done`이다. `project.mjs check`가 문제 없이 끝난다.
   - git 작업 트리가 깨끗하고, 배포할 커밋(또는 태그)이 정해졌다.
   - lock 파일이 있고 `docs/stack.md`의 버전과 맞는다. lock을 쓰지 않는 스택(잠금을 켜지 않은 Gradle 등)은 "확인 불가"로 적는다.
   - 명령 표의 빌드가 성공한다. 빌드 줄이 없으면 1단계에서 빌드 명령을 정해 `docs/stack.md` 명령 표에 더할지 묻는다(빌드가 필요 없는 스택이면 "해당 없음").
   - DB 마이그레이션이 있으면 적용 순서와 되돌리기 방법이 정해졌다.
   - 필요한 환경 변수와 비밀 값의 이름과 위치(배포 대상의 설정 화면, 비밀 저장소)가 정해졌다. 값은 확인하지 않는다.
   - 되돌리기 방법(이전 버전 재배포, 마이그레이션 되돌리기)이 있다.
3. **실행 계획**: 실패나 확인 불가 항목이 있으면 그 목록을 보여 주고 "고친 뒤 다시 / 알고 진행 / 취소"를 묻는다. 진행이면 실행할 명령을 순서대로, 대상 환경과 함께 보여 준다.
4. **실행 전 확인**: 스테이징이 있으면 스테이징부터 한다. 명령마다 "실행 / 건너뜀 / 멈춤"을 묻고 실행한 뒤 출력을 보여 준다. 운영 배포 명령은 스테이징 결과를 보여 준 다음 따로 확인받는다.
5. **배포 후 확인**: 배포된 주소의 상태 확인 경로(예: `/health`)나 사용자가 정한 확인 방법으로 동작을 확인한다. 확인할 방법이 없으면 "배포 후 확인 미실시"로 적는다.
6. **기록**: 배포한 커밋, 환경, 실행한 명령, 결과를 `마이 작업 종료`의 인계 문서에 남기라고 안내한다.

질문은 선택지 질문 도구가 있으면 그것으로 묻고, 없으면 번호 목록으로 묻고 번호로 답을 받는다.

채팅 모드(셸·파일 도구가 없거나 이 스킬 폴더 기준 `../../scripts`가 없음)면 이 본문 대신 같은 폴더의 `chat.md`를 따른다. 스크립트가 실행됐다가 실패한 것은 채팅 모드가 아니다.

## 멈출 때

- 배포 명령이 실패하면 더 실행하지 않고 출력과 되돌리기 방법을 보여 준 뒤 "되돌리기 실행 / 그대로 둠"을 묻는다. 되돌리기도 실행 전 확인을 받는다.
- 로그인·인증·결제 화면이나 비밀 값 입력이 필요하면 멈추고 사용자가 직접 하게 한다.
- 비대화형 실행이면 1~3단계(체크리스트와 실행 계획)만 보여 주고 "승인 대기 — 대화형에서 다시 실행"을 적는다. 배포 명령을 실행하지 않는다.

## 결과

- 끝: 체크리스트 결과, 배포한 커밋과 환경, 실행한 명령과 결과, 배포 후 확인 결과, 되돌리기 방법.

## 하지 말 것

- 확인 없이 배포·마이그레이션·되돌리기 명령을 실행하지 않는다.
- 체크리스트 실패를 숨기고 진행하지 않는다.
