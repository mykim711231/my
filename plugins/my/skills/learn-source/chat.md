# 기존 소스 학습 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

- 첨부한 소스 파일이나 zip만 근거로 하고, 설명마다 파일:줄을 적는다. 받지 못한 파일에 기대는 설명은 "미확인 — <파일> 필요".
- 소스를 고친 코드를 주지 않는다. 학습이 목적이다.

## 할 일

1. 소스가 없으면 첨부를 요청한다. 크면 README, 설정 파일(`package.json` 등), 진입점부터 달라고 한다.
2. 구조, 진입점, 핵심 흐름 하나를 설명하고 질문에 답한다. 흐름마다 질문 하나로 이해도를 점검한다.
3. 노트: `learn-class`의 학습 노트 양식(파일 이름 `미정-<노트 이름>.md`)으로 md를 준다. `sources`에는 읽은 파일 경로를 넣는다.

## 결과

- 구조 설명, 이해도 점검 결과, 노트 md, "번호 미정 — 로컬에서 import" 한 줄.
