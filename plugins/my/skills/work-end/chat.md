# 작업 종료 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

이 대화를 새 채팅 창에서 이어 가도록 인계 md를 준다. 파일을 썼다고 말하지 않는다.

## 할 일

1. 이 대화에서 정한 목표, 결정(이유 한 줄씩), 최종 결과물(코드·문서·답의 위치나 이름), 남은 문제를 정리한다.
2. 아래 양식 그대로 인계 md를 코드 블록 하나로 준다. 저장 위치: 로컬 프로젝트라면 `docs/handoff/<YYYYMMDD-HHMM>.md`.
   - 앞머리와 절 제목은 바꾸지 않는다(로컬 `작업 이어서`·`작업 현황`이 읽는다).
   - "한 일": 목표, 결정, 최종 결과물을 소제목 없이 `- ` 목록으로.
   - "검증 결과", "커밋 메시지 초안": 붙여 넣은 실행 결과가 없으면 "해당 없음(채팅 모드)".
   - "다음 할 일": 새 창이 바로 시작할 수 있게 한 줄에 하나씩 `- ` 목록으로.
   - "주의할 것": 남은 문제, 미확인, 아직 검증하지 않은 코드.
3. 마지막에 새 창에 붙일 첫 메시지를 코드 블록으로 준다: "`마이 작업 이어서` — 첨부한 인계 md를 읽고 다음 할 일 첫 항목부터 시작해 줘."

```markdown
---
branch: ""
spec: ""
---
# 인계 YYYY-MM-DD

## 한 일

## 검증 결과

## 커밋 메시지 초안

## 다음 할 일

## 주의할 것
```

## 결과

- 인계 md, 새 창 첫 메시지, "인계 md를 내려받아 새 창에 첨부하라"는 한 줄.
