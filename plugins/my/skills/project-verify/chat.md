# 프로젝트 검증 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

## 할 일

1. 명세와 붙여 넣은 실행 결과(생성물 다시 생성 diff, 타입 검사, 계약 테스트, E2E)를 받는다. 결과가 없으면 `docs/stack.md` 명령표 기준으로 실행할 명령을 주고 결과를 붙여 달라고 한다.
2. 명령마다 통과·실패·미실행을 판정한다. 출력이 잘려 있으면 "판정 불가 — 전체 출력 필요".
3. 요구사항 ID 추적표(요구사항 → 테스트 → 결과)를 만든다. 테스트가 없는 요구사항은 "미충족".
4. 명세의 "검증 결과" 절에 넣을 md를 준다. 하위 에이전트 검토를 하지 않았으므로 "분리 검토 아님 — 예비 검토"로 적고, 명세를 완료로 바꾸는 것은 로컬 `마이 프로젝트 {name} 검증`에 맡긴다.

## 결과

- 판정 표, 추적표, 검증 결과 md, "분리 검토 아님".
