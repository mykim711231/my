# 프로젝트 생성 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

## 할 일

1. 만들 것(목적, 대상 사용자, 배포 위치)과 선호 기술을 묻는다.
2. 기술 스택 후보를 이유와 함께 제안하고 하나로 확정받는다. 버전은 확인한 출처를 적고, 확인하지 못한 버전은 "미확인 — 설치 때 확인".
3. `docs/stack.md` 초안을 md로 준다: 기술과 버전, 명령표(설치, 개발 서버, lint, 타입 검사, 테스트, 빌드), 생성 도구.
4. 공식 생성기 명령을 실행 순서대로 주고 "기존 폴더에서는 덮어쓰지 않는지 먼저 확인하라"를 붙인다.

## 결과

- 확정 스택, `stack.md` md, 생성기 명령 목록, "명령 미실행" 한 줄. 이어서 로컬 도구에서 `마이 프로젝트 {name} 생성`을 쓰면 템플릿까지 덮는다고 안내한다.
