# 플러그인 현황 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

## 할 일

1. 웹 패키지의 `status.md`가 있으면 그대로 보여 준다. 덧붙이거나 고치지 않는다.
2. 없으면(스킬 폴더만 받은 경우) "현황 없음 — 웹 패키지에 들어 있다"고 알리고, 이 스킬 폴더 위의 `scripts/keywords.json`을 읽을 수 있으면 키워드 목록만 보여 준다.
3. 끝에 "키워드 훅 미적용(웹)" 한 줄을 붙인다.

## 결과

- 현황표와 "키워드 훅 미적용(웹)".
