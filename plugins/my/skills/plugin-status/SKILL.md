# 플러그인 현황

파일을 만들거나 고치지 마라. 이 스킬은 읽기 전용이다.

## 할 일

1. 이 스킬 폴더 기준 `../../scripts/status.mjs`를 Node로 실행한다.
2. 출력된 마크다운을 그대로 보여 준다. 내용을 덧붙이거나 고치지 않는다.
3. 맨 끝에 한 줄을 붙인다: 이 대화에 `[my 키워드 훅]` 표식이 없었으면 "키워드 훅 미적용", 있었으면 붙이지 않는다.

## 멈출 때

- Node가 없거나 스크립트가 실패하면 오류 메시지를 보여 주고 "현황 생성 실패 (Node 필요)"로 끝낸다. 파일을 직접 읽어 표를 만들지 않는다(원본과 어긋날 수 있다).

## 결과

- 끝: 현황 마크다운 + 필요하면 "키워드 훅 미적용" 한 줄.
- 설정을 바꾸려는 요청이면 `마이 플러그인 설정`을 안내한다.
