# 깃허브 학습 (채팅 모드)

> 공통: 첫 줄에 "채팅 모드 — 파일 쓰기·명령 실행 없음"을 쓴다. 파일은 첨부·붙여 넣기로 받고, 결과는 md 코드 블록으로 주며 로컬에 둘 경로를 적는다. 명령은 실행하지 않고 사용자에게 맡긴다.

- 웹 읽기가 되면 저장소 URL에서 README·문서·소스를 읽고, 근거를 커밋 해시가 들어간 파일:줄로 적는다. 커밋을 확인하지 못했으면 "기본 브랜치, 커밋 미확인"으로 적는다.
- 웹 읽기가 안 되면 README와 주요 파일을 붙여 넣거나 zip(GitHub의 Code → Download ZIP)을 첨부해 달라고 한다.
- 저장소 코드는 실행하지 않는다.

## 할 일

1. 구조, 진입점, 핵심 흐름 하나를 설명하고 질문에 답한다. 흐름마다 질문 하나로 이해도를 점검한다.
2. 노트: `learn-class`의 학습 노트 양식(파일 이름 `미정-<노트 이름>.md`)으로 md를 준다. `sources`에는 저장소 URL과 커밋을 넣는다.

## 결과

- 구조 설명, 이해도 점검 결과, 노트 md, "번호 미정 — 로컬에서 import" 한 줄.
