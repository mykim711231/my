# my

`my`는 AI 코딩 도구에서 작업 인계, 코드·논문 학습, 프로젝트 진행, 도구 설정 동기화를 돕는 플러그인입니다. 자기 GitHub 계정에 포크해 설치하고, 필요한 스킬과 명령을 자신의 작업 방식에 맞게 개선할 수 있습니다.

## 설치하고 시작하기

1. 이 저장소를 자기 GitHub 계정에 포크하고, 포크를 로컬에 복제합니다. [포크 및 개선 가이드](docs/Plugin-사용법/README.md)
2. 사용하는 도구의 가이드를 따라 설치하거나 스킬을 엽니다.

   | 도구 | 사용 방식 |
   | --- | --- |
   | [Claude Code](docs/Plugin-사용법/claude-code.md) | 내 포크를 마켓플레이스로 등록하고 `마이 …` 또는 `/my:<스킬>`을 입력합니다. |
   | [Codex](docs/Plugin-사용법/codex.md) | 내 포크를 호환 마켓플레이스로 등록하고 스킬 목록에서 `my` 스킬을 선택합니다. 키워드 훅을 사용하려면 훅을 검토하고 승인합니다. |
   | [Gemini CLI](docs/Plugin-사용법/gemini-cli.md) | 로컬 체크아웃의 `SKILL.md` 경로와 작업 대상을 대화창에 입력합니다. |

3. `plugin-status` 스킬을 열어 버전과 전체 키워드를 확인합니다. 키워드 훅이 동작하면 `마이 플러그인 현황`으로 같은 스킬을 실행할 수 있습니다.

## 무엇을 할 수 있나요?

- **작업 인계** · `마이 작업 시작`으로 프로젝트를 파악하고, `마이 작업 종료`로 인계 문서를 작성합니다. 다음 대화에서 `마이 작업 이어서`로 재개할 수 있습니다.
- **학습** · 수업 자료, 논문, 기존 소스, GitHub 저장소를 함께 읽고 주제별 학습 노트를 작성합니다.
- **프로젝트 진행** · 프로젝트 생성부터 기능 정의, 구현, 검증, 배포까지 단계별 스킬을 사용합니다.
- **설정 동기화** · `마이 설정 동기화 claude->codex`처럼 방향을 지정해 공통 규칙과 스킬의 변경안을 확인합니다.

## 내 포크 개선하기

`plugin_src`를 내 포크의 로컬 체크아웃으로 지정합니다. `plugin-issue`로 개선점을 기록하고, `plugin-apply`에서 수정안과 diff를 검토한 뒤 반영합니다. 도구별 업데이트 절차로 변경을 확인하고, 원본에도 공유하고 싶다면 포크에서 PR을 열 수 있습니다. [포크 설정과 개선 절차](docs/Plugin-사용법/README.md#내-포크에서-개선하기)
